## Prerequisites

Before starting, ensure you have:

- A Linux server (Ubuntu 20.04+), a Mac, or Windows with WSL2 (Ubuntu)
- 4 GB RAM minimum (8 GB recommended)
- Exchange API keys with trade permissions
- A **Telegram** account and bot token — unless you install in [Local](/getting-started/installing#local), which needs neither
- Access to an LLM provider (Claude, Gemini, Copilot, Codex, OpenRouter, Ollama or LM Studio, or a custom OpenAI-compatible endpoint) for agent reasoning. See [LLM Integration](/llm-integration)
- **[Tailscale](https://tailscale.com) account** (free tier is enough) — recommended when Condor and Hummingbot API run on different machines or any production VPS setup
