Before Condor can trade, the Hummingbot API server needs your exchange keys. You add them in the Workspace. Telegram can show which exchanges are connected, but it can't add or remove keys.

<Note>
Keys are stored on the Hummingbot API server that is selected in the Workspace's top bar, not in Condor itself. Only the server's owner can add or remove keys and wallets. Other users see the buttons disabled.
</Note>

## Add an exchange API key

<Steps>
  <Step title="Open Keys and Wallets">
    In the Workspace, open **Settings → Keys and Wallets**.
  </Step>
  <Step title="Click Add API Key and choose a type">
    Pick **Spot** or **Perpetual**.
  </Step>
  <Step title="Choose the exchange">
    The list shows the connectors your API server supports for that type. Exchanges that already have a key are marked and can't be picked again.
  </Step>
  <Step title="Fill in the fields and save">
    The fields come from the connector, so they differ by exchange. Most ask for an API key and secret. The **How to connect** link next to the title opens that exchange's guide on hummingbot.org.

    When you save, the API server starts the connector with the new key and reads your balances. If that fails, the key isn't saved and the Workspace shows the server's error.
  </Step>
</Steps>

<Warning>
Give API keys only **read** and **trade** permissions. Never enable withdrawals or transfers. Restrict the key to your API server's IP address if the exchange allows it.
</Warning>

### Which exchanges are supported

The list of exchanges comes from your Hummingbot API server, so it depends on the version you run. To see it, click **Add API Key** and choose **Spot** or **Perpetual**. The Workspace doesn't list testnet, sandbox or Gateway (DEX) connectors here.

## Connect Hyperliquid

Hyperliquid uses a one-click wallet flow instead of a pasted key. You don't share your wallet's private key with Condor.

<Steps>
  <Step title="Start the flow">
    In **Settings → Keys and Wallets**, click **Add API Key**, then **Connect Hyperliquid**. Choosing Hyperliquid from the exchange list opens the same flow.
  </Step>
  <Step title="Name the agent wallet">
    The **Agent name** is pre-filled, for example `condor-20261014`. You can edit it. Hyperliquid allows up to 16 letters, numbers and dashes.
  </Step>
  <Step title="Connect your browser wallet">
    Pick your wallet, such as Rabby or MetaMask. Condor asks it to switch to Arbitrum One, which Hyperliquid uses for signing.
  </Step>
  <Step title="Approve the agent wallet">
    Condor creates a new agent wallet in your browser. You sign an approval that lets it trade for your account. It can't withdraw.
  </Step>
  <Step title="Approve the builder fee">
    You sign an approval for the Condor builder fee (see below). If your account has already approved it, this step is skipped.
  </Step>
  <Step title="Done">
    Condor saves the agent wallet's key and your main address as credentials for **both** `hyperliquid` (spot) and `hyperliquid_perpetual`. The screen shows the date the agent wallet expires.
  </Step>
</Steps>

**What you agree to:**

| | Details |
|---|---|
| **Agent wallet validity** | 180 days, which is Hyperliquid's maximum. Reconnect before it expires. After that date the agent wallet can't trade. |
| **Builder fee** | A builder fee of up to **1 bps (0.01%)** on trades placed through these Hyperliquid connectors. It goes to the not-for-profit Hummingbot Foundation to support Condor's maintenance. The approval is required to finish the connection. |
| **Referral code** | After connecting, Condor offers to link the `HUMMINGBOT` referral code, which gives your account **4% off** Hyperliquid trading fees. This is optional. Click **Link code** or **Skip**. Hyperliquid allows one referral code per account, so it isn't offered if your account already has one. |

To reconnect, remove the existing Hyperliquid keys first. **Connect Hyperliquid** is disabled while they exist.

## Add a Gateway wallet

DEX trading and liquidity positions go through Gateway, which signs transactions with a wallet stored on your server.

1. Make sure Gateway is running. **Add Wallet** is disabled until it is. You can start Gateway from the **Gateway** tab.
2. In **Settings → Keys and Wallets**, click **Add Wallet**.
3. Choose **Solana** or **Ethereum/EVM**.
4. Paste the wallet's private key. Browser wallets don't share private keys with apps, so export it from your wallet first.
5. Leave **Set as default wallet for this chain** ticked if Condor should use this wallet by default.

Use a wallet that holds only what you're prepared to trade with. For a full DEX example, see [Guide: Solana DEX LP Expert Agent](/examples/solana-lp).

## Check what's connected

- **Workspace:** **Settings → Keys and Wallets** lists your API keys by type, and your Gateway wallets.
- **Telegram:** send `/keys`. Condor lists the connected exchanges on your active server and gives a link to the Workspace to add or remove keys. The link is valid for 5 minutes.
- **Balances:** see [Portfolio](/getting-started/portfolio).

## Troubleshooting

<AccordionGroup>
  <Accordion title="Saving a key fails">
    The error comes from the API server, which tried to start the connector with your key. Check the key and secret, that the key is active, and that it has trading permission. If you restricted the key by IP address, make sure your API server's IP is allowed.
  </Accordion>
  <Accordion title="Add API Key or Add Wallet is disabled">
    Only the server's owner can change keys and wallets. **Add Wallet** also needs Gateway to be running.
  </Accordion>
  <Accordion title="Hyperliquid says the wallet reached its agent limit">
    Remove an unused API wallet in the Hyperliquid app, then connect again.
  </Accordion>
  <Accordion title="Hyperliquid stopped trading">
    The agent wallet may have expired. Remove the Hyperliquid keys in **Settings → Keys and Wallets** and connect again.
  </Accordion>
  <Accordion title="Hyperliquid says the account isn't funded">
    Hyperliquid won't authorize an agent wallet or builder code until the wallet has made a deposit. Deposit USDC to Hyperliquid from that wallet, then connect again.
  </Accordion>
</AccordionGroup>
