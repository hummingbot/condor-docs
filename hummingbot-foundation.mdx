The **Hummingbot Foundation** is an open source foundation. It maintains Condor, Hummingbot and Hummingbot API as free, public, auditable code, and runs the community around them.

<Note>
  **Our mission is to democratize algorithmic trading:** to make sophisticated trading strategies and technology available to everyone, not only to professional firms.
</Note>

## Open source projects

The Foundation maintains these repositories. Each one is free to use, fork and contribute to.

<CardGroup cols={2}>
  <Card title="Hummingbot" icon="github" href="https://github.com/hummingbot/hummingbot">
    The open source framework for building and running automated trading strategies on centralized and decentralized exchanges.
  </Card>
  <Card title="Hummingbot API" icon="github" href="https://github.com/hummingbot/hummingbot-api">
    The server that manages Hummingbot bots, executors, exchange accounts and Gateway. It is the execution layer that Condor drives.
  </Card>
  <Card title="Condor" icon="github" href="https://github.com/hummingbot/condor">
    The open source harness for Condor Agents: the Workspace, the Telegram bot and LLM agents on top of Hummingbot API. These docs cover it.
  </Card>
</CardGroup>
