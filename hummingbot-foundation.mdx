**Hummingbot Foundation** is a not-for-profit organization established in the Cayman Islands in 2021.

<Note>
  **The Foundation's mission is to democratize high-frequency trading** by maintaining the open-source Hummingbot code repositories and the HBOT governance system.
</Note>

## About the Foundation

Hummingbot was built and open sourced by CoinAlpha in April 2019. In December 2021, CoinAlpha spun off the Foundation as an independent open source entity to maintain the Hummingbot repositories and run a community-driven governance system using the HBOT token.

Its work follows four principles: the code is **open source** (public, auditable and free), **modular** (community members can build and maintain parts independently), **extensible** (any strategy on any exchange or blockchain), and built for **all levels**, from individuals to professional firms.

A small, globally distributed staff handles the day-to-day work: reviewing and merging pull requests, running governance proposals and elections, managing developer bounties and the Discord server, packaging releases and maintaining the documentation.

For the full history, bylaws and governance details, see [About Hummingbot Foundation](https://hummingbot.org/about/).

## Open source repos

The Foundation actively maintains these core repositories. Each one is free to use, fork and contribute to.

| Repo | What it is |
|---|---|
| [Condor](https://github.com/hummingbot/condor) | The harness for Condor Agents: the Workspace, the Telegram bot and LLM agents on top of Hummingbot API. These docs cover it |
| [Hummingbot](https://github.com/hummingbot/hummingbot) | The framework for building and running automated trading strategies on centralized and decentralized exchanges |
| [Hummingbot API](https://github.com/hummingbot/hummingbot-api) | The server that manages Hummingbot bots, executors, exchange accounts and Gateway. It is the execution layer that Condor drives |
| [Gateway](https://github.com/hummingbot/gateway) | The service for DEX trading: swaps and liquidity pools on decentralized exchanges. Condor reaches it through Hummingbot API |
